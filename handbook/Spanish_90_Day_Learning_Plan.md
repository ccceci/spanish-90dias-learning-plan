# 墨西哥西班牙语 90 天实用学习计划
## Mexican Spanish – 90-Day Practical Learning Plan

**学习起点：** A0 初学者  
**目标：** 建立 A2 左右的日常沟通能力  
**学习时间：** 每天 75–90 分钟，每周 6 天  
**学习重点：** 墨西哥日常生活、工作沟通、听力与口语

---

# 一、每日学习方法

每天按照以下时间安排：

| 内容 | 时间 | 任务 |
|---|---:|---|
| 听力 | 15分钟 | 听初级西班牙语材料 |
| 词汇与句型 | 15分钟 | 学习8–10个常用表达 |
| 跟读 | 15分钟 | 模仿发音、语调 |
| 口语 | 20分钟 | 自我表达、情景对话 |
| 复习 | 10分钟 | 回顾当天内容 |

每周第7天为复习日，不增加大量新知识。

# 二、90天课程安排

## 第一阶段：基础交流（第1–30天）

### 第1周：打招呼与自我介绍
- Day 1：Hola、Buenos días、Buenas tardes、Buenas noches
- Day 2：姓名与自我介绍：Me llamo… / Soy…
- Day 3：国籍与城市：Soy de China. Vivo en México.
- Day 4：职业：Soy arquitecta. / Trabajo en…
- Day 5：礼貌表达：Por favor、Gracias、De nada、Perdón
- Day 6：完成一分钟自我介绍
- Day 7：复习本周全部表达

### 第2周：数字、时间与日期
- Day 8：数字0–20
- Day 9：数字21–100
- Day 10：100–999
- Day 11：星期、月份与日期
- Day 12：询问时间：¿Qué hora es?
- Day 13：询问年龄、电话号码与价格
- Day 14：复习数字和时间

### 第3周：日常生活与动词
- Day 15：常用动词：ser、estar、tener
- Day 16：ir、hacer、trabajar、vivir
- Day 17：日常作息：levantarse、desayunar、dormir
- Day 18：现在时第一组规则动词
- Day 19：描述每天的安排
- Day 20：谈论工作日和休息日
- Day 21：复习与口语测试

### 第4周：餐饮与点餐
- Day 22：食物和饮料
- Day 23：餐厅常用词汇
- Day 24：点餐：Quisiera…
- Day 25：询问菜单和价格
- Day 26：表达数量和偏好
- Day 27：模拟餐厅完整对话
- Day 28：复习

### 第5周：购物与价格
- Day 29：颜色、衣服和尺寸
- Day 30：购物常用表达
- Day 31：询价：¿Cuánto cuesta?
- Day 32：数量：uno、dos、medio kilo
- Day 33：比较价格与商品
- Day 34：付款与购物对话
- Day 35：复习

## 第二阶段：生活交流（第36–60天）

### 第6周：交通与问路
- Day 36：地点与方向

### 第8周：社交与兴趣
- Day 50：兴趣爱好
- Day 51：表达喜欢：Me gusta…
- Day 52：表达不喜欢：No me gusta…
- Day 53：邀请别人：¿Quieres…?
- Day 54：接受或婉拒邀请
- Day 55：介绍自己的周末安排

### 第9周：职场西班牙语
- Day 57：职业和工作岗位
- Day 58：办公用品与工作场所

## 第三阶段：实际应用（第64–90天）

- Day 65：规则动词过去时

- Day 77：复习

### 第12周：综合交流
- Day 78：自我介绍与个人信息
- Day 79：餐厅和购物场景
- Day 80：交通和问路场景

# 三、墨西哥生活必备表达

| 西班牙语 | 中文 |
|---|---|
| ¿Me puede ayudar? | 您能帮我吗？ |
| ¿Puede hablar más despacio? | 您能说慢一点吗？ |
| No entendí. | 我没听懂。 |
| ¿Puede repetir? | 可以重复一遍吗？ |
| ¿Qué significa? | 这是什么意思？ |
| ¿Cómo se dice en español? | 用西班牙语怎么说？ |
| ¿Me lo puede escribir? | 可以写给我吗？ |
| Está bien. | 好的。 |
| No hay problema. | 没问题。 |
| Muchas gracias. | 非常感谢。 |

# 四、职场必备表达

| 西班牙语 | 中文 |
|---|---|
| ¿Qué tengo que hacer? | 我需要做什么？ |
| ¿Cuál es la prioridad? | 哪件事情优先？ |
| ¿Para cuándo lo necesita? | 您什么时候需要？ |
| ¿Me puede explicar? | 您能给我解释一下吗？ |
| Voy a revisar el archivo. | 我会检查文件。 |
| Ya terminé. | 我已经完成了。 |
| Todavía no está listo. | 还没有准备好。 |
| ¿Hay algún cambio? | 有什么修改吗？ |
| Necesito más tiempo. | 我需要更多时间。 |
| ¿Puede confirmar las medidas? | 可以确认一下尺寸吗？ |

# 五、优先掌握的语法

1. 名词阴阳性和单复数。
2. 定冠词与不定冠词：el、la、los、las、un、una。
3. ser 与 estar 的区别。
4. tener、ir、hacer、querer、poder 的常用变位。
5. 规则动词现在时。
6. gustar 结构。
7. hay 与 estar 的区别。
8. 疑问词：qué、quién、dónde、cuándo、cuánto、cómo、por qué。
9. ir a + 动词原形。
10. 常见过去时表达。

# 六、90天学习验收标准

**第30天：**
能够介绍自己、说数字、时间、日常安排，并完成简单点餐和购物。

**第60天：**
能够问路、描述住处、进行简单社交，并表达基本工作需求。

**第90天：**
能够描述过去经历、表达近期计划，处理常见生活场景，并完成约5分钟的简单连续对话。

**核心原则：每天听、每天说、每天复习。不要只背单词，要把学到的表达真正用出来。**
