# Spanish 90-Day Learning Resources
## 墨西哥西班牙语90天学习资源目录

本目录按照12周学习计划整理，重点是初级听力、墨西哥口音、日常会话和职场交流。

---

# 一、核心学习平台

## 1. Dreaming Spanish

网站：https://www.dreamingspanish.com/

YouTube：https://www.youtube.com/@DreamingSpanish

**推荐等级：★★★★★**

适合：零基础、初级听力。

学习阶段：
- Superbeginner：第1–4周
- Beginner：第5–8周
- Intermediate：第9–12周（根据理解程度选择）

使用方法：
1. 先不看字幕听一遍。
2. 尝试理解视频大意。
3. 第二遍结合西班牙语字幕。
4. 最后跟读3–5个句子。

## 2. Butterfly Spanish

YouTube：https://www.youtube.com/@ButterflySpanish

**推荐等级：★★★★★**

适合：基础语法、词汇、发音和初级句型。

推荐搜索：
- Spanish greetings
- Spanish numbers
- Spanish verbs
- Spanish present tense
- Spanish pronunciation

## 3. Easy Spanish

YouTube：https://www.youtube.com/@EasySpanish

**推荐等级：★★★★★**

适合：真实对话、街头采访、自然语速。

重点：
- 优先选择墨西哥街访。
- 先理解关键词，不要求听懂每一个单词。
- 注意当地人的表达方式和口语习惯。

## 4. Spanish and Go

网站：https://spanishandgo.com/

适合：墨西哥生活、旅行、文化和实际表达。

## 5. Spring Spanish

YouTube：https://www.youtube.com/@SpringSpanish

适合：日常交流、常用短语和自然表达。

## 6. Language Transfer

网站：https://www.languagetransfer.org/complete-spanish

适合：理解西班牙语句子结构，培养主动组织句子的能力。

## 7. Coffee Break Spanish

网站：https://coffeebreaklanguages.com/coffeebreakspanish/

适合：有系统的初级听力课程。

# 三、墨西哥西班牙语专项资源

建议特别关注以下内容：

1. Easy Spanish 的墨西哥街头采访。
2. Spanish and Go 的墨西哥生活主题。
3. Dreaming Spanish 中来自墨西哥的讲述者。
4. 墨西哥日常生活、餐厅、超市和工作场景视频。

常见墨西哥表达：

| 表达 | 意思 |
|---|---|
| ¿Qué onda? | 怎么样？最近好吗？（非正式） |
| Ahorita | 现在、马上或一会儿，具体看语境 |
| Mande | 您说？/请再说一遍？ |
| Chido | 很棒、很酷 |
| Órale | 哦、好啊、加油等，依语境而定 |
| No manches | 不会吧！/真的假的！（非正式） |

这些表达有语境和正式程度区别，初学阶段先理解即可，不必急着使用。

# 四、每天听力训练方法

每天15–20分钟：

**第一遍：** 不看字幕，听懂大意。

**第二遍：** 打开西班牙语字幕，核对听到的内容。

**第三遍：** 暂停并跟读，模仿语调。

**第四步：** 用自己的话说出3–5句内容。

建议每周反复使用3–5段材料，而不是每天不停更换视频。
